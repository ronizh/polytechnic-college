# Polytechnic College — Digital Campus

Портал колледжа: личные кабинеты студента, преподавателя и администратора, электронный журнал, расписание, задания, новости, аналитика.

## Запуск
```bash
python -m venv .venv
.venv\Scripts\activate        # Windows  (Linux/macOS: source .venv/bin/activate)
pip install -r requirements.txt
cd backend
uvicorn main:app --reload
```
Откройте http://127.0.0.1:8000 — при первом запуске создаются `backend/campus.db` и демо-данные
(20 студентов, 5 преподавателей, 4 группы, 8 предметов, оценки, расписание, новости).

## Демо-аккаунты
| Роль | Логин | Пароль |
|---|---|---|
| Администратор | admin | admin123 |
| Преподаватель | teacher1 … teacher5 | teacher123 |
| Студент | student1 … student20 | student123 |

Чтобы сбросить данные — удалите `backend/campus.db` и перезапустите сервер.
Swagger-документация API: http://127.0.0.1:8000/docs

## Структура
- `backend/main.py` — FastAPI: REST API, роли, оценки с историей, посещаемость, экспорт, админ-функции, демо-данные.
- `frontend/` — интерфейс (HTML + CSS + JS, Chart.js по CDN), раздаётся тем же сервером.

## Безопасность
Пароли — PBKDF2-SHA256 с солью; подписанные токены (HMAC) на 24 часа; проверка роли на каждом endpoint;
преподаватель меняет оценки только по своим предметам; студент видит только свои данные; валидация входа через Pydantic;
вывод экранируется на клиенте. Для продакшена задайте переменную `SECRET_KEY` и включите HTTPS.

## Что не реализовано (честно)
Фронтенд на чистом JS, а не React/TypeScript/Tailwind; БД — SQLite вместо PostgreSQL (для PostgreSQL замените слой `db()`);
экспорт в PDF — через «Печать / PDF» браузера, в Excel — CSV (открывается в Excel); редактирование расписания и фото профиля — нет.
